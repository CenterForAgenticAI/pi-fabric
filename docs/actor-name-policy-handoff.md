# Actor name decision: proof handoff

`src/actors/name-policy.ts` is a pure decision on two booleans derived from a host snapshot of exact trimmed-name matches. Its complete truth table is: active wins whenever present; otherwise stopped wins whenever present; otherwise available. Candidate laws: available iff neither flag is set; active iff active is set; stopped iff stopped is set and active is not. Decisions have no side effects. Both create adapters refuse before directory creation or automatic deletion for either non-available result; explicit removal is a separate operation.

The proof boundary does not include snapshot completeness, actor lookup, error construction, filesystem, persistence, deletion, or adapter control flow. Manager uses its local loaded view; directory combines its visible project and session views. Neither decision reserves a name: asynchronous validation and independent hosts can race, and no distributed uniqueness, ownership, crash recovery, or execution fencing is established. Concurrent requests observing an existing stopped name are all refused; no name reservation or serialization is added. A failed registry write for a different new actor is tested not to delete the old stopped actor or its session, but other failure behavior for that new actor remains unchanged. Proof integration must compare the shipped function to its model, check all four inputs and a broken variant, and independently review these assumptions. No proof has been integrated here.
